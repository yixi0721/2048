# 2048

奶油色主题的本地 2048 网页游戏，无需安装第三方依赖。支持手机触控和电脑方向键、4×4 与 5×5 棋盘、普通模式与纯净模式、主题皮肤、道具、成就和本地存档。

## 启动

需要 Node.js。进入项目目录运行：

```sh
npm start
```

然后打开 <http://localhost:8080/>。也可以运行 `node server.js`。请通过本地服务访问页面，直接双击 HTML 无法加载 ES modules。

## 构建与测试

```sh
npm run build
npm test
```

构建产物位于 `dist/`。完整 Android 工程可用同一套网页资源构建 Android APK。

## 数据与玩法

- 普通模式和纯净模式各自保存 4×4、5×5 棋局、最高分、合成统计和成就。纯净模式不提供道具。
- 奶油、薄荷、蜜桃、月夜初始可用；挑战皮肤在首次合成 128、256、512、1024 时依次解锁。
- 每种道具最多存 50 个；道具获取和本局使用次数见道具抽屉。
- 主题、棋局、分数和设置保存在本机浏览器存储中。
